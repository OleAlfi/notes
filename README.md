# Notes - this is a test project to learn django

## Tech Stack
- **Backend:** Python 3.13, Django
- **Frontend:** HTML5, CSS3 (Custom Dark Theme), Bootstrap 5.3
- **Database:** SQLite (Development standard)

## How to run
- **Clone repository**
- **Create new virtual env:** python -m venv venv
- **Install libraries:** pip install -r requirements.txt
- **Run server:** python manage.py runserver
